# The Crownmaster’s Manual — Rebuilt Edition

197 pages; 55098 words; 100 newly composed and exhaustively verified mate exercises. This is a rebuilt replacement, not the missing original 217-page file.

Open PDF in Files or EPUB in Apple Books. HTML is self-contained offline; Markdown and diagrams are editable. The text is an edited and expanded selection of the owner’s checked Grimoire, organised into ten parts with a separate new workbook answer key. No game changes or deployment.

Verification: 283 source positions passed the published checker; all 100 new mate problems were exhaustively checked against every legal defence. Finite engine preferences and simplified DTM models remain labelled as limited. Source scripts and raw records are included.

Rebuild from repository root: `node node_modules/tsx/dist/cli.mjs docs/crownmasters-manual-rebuilt/source/prepare.ts`, then `python3 docs/crownmasters-manual-rebuilt/source/build.py`. Requires locked project dependencies, Pandoc, XeLaTeX, Pillow and DejaVu fonts.
